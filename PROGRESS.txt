REMAINING / OPTIONAL (not blocking release)
-------------------------------------------
- Browser-only manual QA on real Chrome/Safari/iOS (no browser binary in this
  environment): WebGL scenes, path tracer, touch gestures, install prompt.
- True interruptible Stop requires moving interpreter execution into a Worker.
- Modeler route keeps its own compact token set (ui.css is not loaded there);
  converting its remaining dialogs would need a shared token layer.
- Source maps are opt-in: `npm run build -- --sourcemap`.
- `scrollIntoView` is feature-detected in the palette and project-search list so
  non-visual DOMs (jsdom, very old WebViews) cannot throw during keyboard nav.

KNOWN LIMITATIONS (do not “fix” with fake UI)
---------------------------------------------
- Interpreter is synchronous on the main thread. Real Stop needs a Worker
  rewrite; the disabled Stop button was removed instead of faked.
- Browser-stored hosted AI keys are never fully secret; default is session-only
  with explicit remember opt-in and a documented server-proxy recommendation.
- APK compilation stays a GitHub Actions workflow, not an in-browser build.
- WebGL renderer and CPU path tracer are lightweight, not Unreal/Blender.
